## Executive result

- 42 indexable URLs were individually queried in Search Console.
- 30 pages had at least one impression; 12 had no page-level impression row in this three-day window.
- The 42 page-insight rows summed to 250 impressions and 2 clicks (0.8% page-impression-weighted CTR). This is a sum of page-dimension rows, not a substitute for the Search Console property overview.
- The homepage recorded 2 clicks from 17 impressions (11.76% CTR, average position 3.18).
- The Years to Days Calculator accounted for 154 impressions (61.6% of the page-impression sum), but had 0 clicks and an average position of 62.87.
- The Tasbih Counter had 25 impressions, 0 clicks and an average position of 8.80. Its exact query `tasbih calculator` received 12 impressions at position 8.42.
- No previous-period comparison is available in this connected free view. Low sample sizes must not be treated as stable ranking or CTR benchmarks.

## Actual query rows returned by Search Console

### Tasbih Counter

| Query | Clicks | Impressions | Avg. position |
|---|---:|---:|---:|
| tasbih calculator | 0 | 12 | 8.42 |
| calculator tasbih | 0 | 4 | 10.00 |

The current title already includes the exact `Tasbih Calculator Online` and `Dhikr Counter` intent. The PR branch updates the 146-character description to state the free online tool, supported 33/99/custom targets, undo, browser-local progress and no sign-up. This is a snippet test, not a ranking guarantee. Do not repeat the phrase unnaturally.

### Unit Converter

| Query | Impressions | Avg. position |
|---|---:|---:|
| cm into kg | 1 | 80.00 |

A future content improvement can make the supported pairs more explicit (for example, cm to inches and kg to lbs) without creating thin doorway pages.

## Opportunity shortlist from the connected Search Console integration

The opportunity endpoint independently returned six candidates for 2026-11-08 through 2026-11-10:

1. **Years to Days page, low CTR:** 154 impressions, 0 clicks, 0% CTR, average position 62.87. Recommendation: improve page relevance and snippet; the title override is the first confirmed fix.
2. **Tasbih query `tasbih calculator`:** 12 impressions, average position 8.42. Recommendation: protect exact-intent alignment and compare snippet wording against current SERP competitors.
3. **Tasbih page, low CTR:** 25 impressions, 0 clicks, average position 8.80. The sample is small; monitor rather than making several simultaneous snippet changes.
4. **Unit Converter page, low CTR:** 9 impressions, average position 56.56. Review query relevance; the three visible queries are invalid conversion pairs and should not be targeted.
5. **Tasbih query `calculator tasbih`:** 4 impressions, average position 10.00. Treat as a variant of the same page intent, not a separate landing page.
6. **Years to Days query `800000/365`:** 2 impressions, average position 7.50. This is a specific arithmetic expression with too little data to justify a separate page.

## Technical SEO status from the repository build

The current build pipeline already enforces the following across generated pages:

- Unique page titles and descriptions for indexable pages.
- Self-referencing production canonicals.
- Index/noindex decisions and sitemap consistency.
- Valid JSON-LD parsing and page-level entities.
- 42 indexable URLs and 5 deliberately noindex locale homepages.
- Internal-link targets and trailing-slash canonical routes.
- `llms.txt` coverage of all sitemap URLs.

A new all-indexable-pages regression test is being added to check every indexable HTML page for one H1, title, description, canonical, robots directive, language declaration, image alt text, JSON-LD and sitemap membership. The test must ignore HTML-like strings inside inline scripts, as the EMI calculator's security test intentionally contains an `<img onerror=...>` string.

## Keyword research file quality

`research/keyword-candidates-2026-10.csv` contains 300 rows across 12 calculator slugs. All 300 rows are explicitly marked `editorial brainstorming` and `unverified`. Many are repetitive modifiers such as "for beginners", "on mobile", "without signup" and "instant result". They are not measured search volumes, validated keyword difficulty or confirmed buyer/search demand. Do not use them as proof of traffic potential or blindly place all of them on pages.

## Limitations

- The free Search Console connector view exposes only 2026-11-08 to 2026-11-10 and no comparison period. Query rows can be omitted by Search Console privacy thresholds.
- A page with no impressions in this window is not proven unindexed or technically broken.
- No keyword volume or difficulty is claimed where the source did not provide it.
- Search Console impressions and positions do not prove ChatGPT citations.
- Allowing OAI-SearchBot improves ChatGPT Search eligibility but cannot guarantee that a page is selected for a particular answer.
